# 21 — Examen práctico: JS → React → Redux

Simula el examen: una **app funcional en JavaScript** que migras primero a **React** y después a **Redux**. Pensado para hacerlo en **~3 h** en total.

## Contenido

- **`app-vanilla/`** — App lista de tareas en JavaScript base (estado, fetch, añadir, marcar, borrar, filtro). Ábrela con el navegador (`index.html`) o `npx serve app-vanilla`.
- **`PLAN-EXAMEN-JS-REACT-REDUX.md`** — Plan paso a paso: Parte 1 (JS → React, ~1 h), Parte 2 (React → Redux, ~1 h), con checklist y tiempos.

## Orden recomendado

1. Ejecutar y entender la app en `app-vanilla/` (estado, funciones, render).
2. Crear proyecto React y migrar siguiendo la Parte 1 del plan.
3. Añadir Redux al proyecto React siguiendo la Parte 2 del plan.

Guía React: [javascript-guia/docs/19-react-desde-cero.md](../../javascript-guia/docs/19-react-desde-cero.md). Redux: [20-react-redux-bridge.md](../20-react-redux-bridge/README.md) y [javascript-guia/docs/20-react-redux-bridge.md](../../javascript-guia/docs/20-react-redux-bridge.md).
