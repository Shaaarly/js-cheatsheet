# Datos iniciales para ejercicios (javascript-guia)

**Los datos de partida están ya incluidos en cada archivo de ejercicio** (debajo del título, en la sección "--- Datos de partida ---"). Así puedes ir de un ejercicio a otro sin cambiar de archivo.

Este archivo se mantiene como **referencia** por si quieres ver todos los bloques en un solo sitio o copiar datos alternativos (por ejemplo para probar con otros valores). Si un ejercicio no tiene bloque "Datos de partida", el enunciado no pide datos concretos o incluye una breve indicación de qué usar.

---

Para ver los datos en contexto, abre la carpeta del capítulo (p. ej. `01-basics/`) y el archivo del ejercicio (p. ej. `ejercicio-3.js`). Los datos están al inicio del archivo, listos para usar.
