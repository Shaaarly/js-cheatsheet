# 19 - React desde cero

Ejercicios del [cap. 19 de la guía](../../javascript-guia/docs/19-react-desde-cero.md). Son **mini apps** para hacer en un proyecto React (Vite).

**Crear proyecto:** `npm create vite@latest mi-app -- --template react` → `cd mi-app` → `npm install` → `npm run dev`.

Cada ejercicio indica qué implementar; los archivos en esta carpeta solo tienen el enunciado y datos base (URLs, etc.). Implementa en tu proyecto (p. ej. en `App.jsx` o en componentes separados).
