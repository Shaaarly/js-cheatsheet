# 20 - React + Redux

Ejercicios del [cap. 20 de la guía](../../javascript-guia/docs/20-react-redux-bridge.md), sección Mini-ejercicios.

**Estructura:** Cada ejercicio tiene su directorio (`ejercicio-1/` … `ejercicio-6/`) con `README.md` y `enunciado.js` (o datos de partida). Dentro de cada carpeta puedes crear un proyecto Vite+React+Redux para practicar (`npm create vite@latest . -- --template react`, luego `npm install @reduxjs/toolkit react-redux`).

**Alternativa:** Si has hecho la ruta Pokedex del tema 19, migra esa app a Redux siguiendo la parte "Tema 20" de [PLAN-POKEDEX.md](../19-react-desde-cero/PLAN-POKEDEX.md) en el mismo proyecto `19-react-desde-cero/pokedex-app/`.

**Linter (obligatorio):** En el examen no puede haber ningún error de linter. En todos los ejercicios (y en la Pokedex con Redux) instala ESLint, configúralo para React y haz que `npm run lint` termine sin errores. Cada README de ejercicio incluye los pasos.
